# 图书管理系统测试计划
## 1. 测试目的
对图书管理系统所有核心业务模块进行全面测试，验证系统功能是否符合需求，发现潜在缺陷，保障系统稳定可用。

## 2. 测试范围
### 2.1 功能测试范围
- 登录功能（正向、反向、异常）
- 图书新增功能
- 图书列表展示功能
- 图书模糊查询功能
- 图书编辑功能
- 图书删除功能

### 2.2 接口测试范围
- 获取图书列表接口
- 新增图书接口
- 查询单本图书接口
- 修改图书接口
- 删除图书接口

## 3. 测试类型
- 手工功能测试
- 边界值测试
- 异常场景测试
- 接口功能测试
- 自动化回归测试

## 4. 测试环境
- 浏览器：Chrome 最新版
- 接口地址：https://jsonplaceholder.typicode.com
- 测试工具：Postman、Excel、PyCharm、Allure

## 5. 测试周期
1. 需求分析 + 测试计划编写
2. 测试用例设计
3. 手工测试执行 & 缺陷提交
4. 接口手工测试
5. 自动化脚本开发
6. 生成测试报告 & 项目总结

## 6. 测试资源
- 测试人员：1人
- 工具：Typora、Excel、Postman、Python、Pytest、Allure、Git

## 7. 交付产物
1. 全套测试文档（需求、计划、用例、缺陷、总结）
2. Excel 功能测试用例
3. 接口自动化测试脚本
4. Allure 可视化测试报告
5. GitHub 完整开源项目

## 8. 测试风险
1. 前端校验不完善，存在非法数据入库风险
2. 删除操作无二次强校验，易误删
3. 部分接口异常场景未做拦截

## 9. 测试标准
1. 核心 P0 用例 100% 通过
2. 严重、高危缺陷全部修复
3. 所有业务流程可正常闭环
